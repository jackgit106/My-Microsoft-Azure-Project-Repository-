# Azure Data Fundamentals (DP-900) – Cloud & Data Services Project

## Project Overview

This project was completed as part of an **Azure Data Fundamentals (DP-900) training course** and focused on developing a practical understanding of **cloud computing, data services, data ingestion, and data analysis within Microsoft Azure**.

The project explored how different Azure data services can be used to store, ingest, manage, and analyse data, using datasets such as **retail and sales data** to apply practical data skills.

## Cloud Computing & Azure Fundamentals

- Developed an understanding of **cloud computing concepts** and how cloud-based data services support modern organisations
- Explored key Azure data services and their different use cases
- Gained an understanding of how **relational, non-relational, and analytical workloads** can be managed using Azure
- Explored how different Azure services can work together within a broader data ecosystem

## Azure Data Services

### Azure SQL Database

Worked with **Azure SQL Database** to understand relational data and structured datasets.

Practical SQL skills included:

- `SELECT` – retrieving relevant data from tables
- `WHERE` – filtering records based on specific conditions
- `ORDER BY` – sorting and comparing results
- `GROUP BY` – grouping and summarising data
- `JOIN` – combining data from multiple related tables

These techniques were applied to datasets such as **retail and sales data** to analyse information and extract useful insights.

### Azure Storage Account

Explored **Azure Storage Account** as a solution for storing non-relational data and understanding how cloud storage can support different data types and workloads.

### Azure Cosmos DB

Developed an understanding of **Azure Cosmos DB** and its role as a globally distributed, non-relational database service.

This provided practical experience with concepts surrounding **NoSQL data, flexible data structures, and non-relational workloads**.

### Microsoft Fabric Lakehouse

Explored **Microsoft Fabric Lakehouse** and its role in supporting analytical workloads.

The project demonstrated how a Lakehouse approach can bring together data for **storage, processing, analysis, and reporting**, providing a foundation for modern data analytics.

## Data Ingestion

Explored different approaches to **data ingestion** within the Azure and Microsoft data ecosystem, including:

- **Eventstreams** for ingesting and processing streaming data
- Importing and loading datasets into cloud-based data services
- Understanding how batch and streaming ingestion can support different data requirements
- Moving data between different services for storage and analysis

This provided an understanding of how data can flow from its source through ingestion and storage before being prepared for analytical workloads.

## SQL Data Analysis

Practical SQL queries were used to analyse and extract insights from datasets, including retail and sales data.

Examples of analysis included:

- Filtering sales records using `WHERE`
- Sorting sales results using `ORDER BY`
- Grouping sales by categories, products, or other dimensions using `GROUP BY`
- Combining related tables using `JOIN`
- Selecting relevant fields and records using `SELECT`
- Using SQL to investigate patterns, trends, and relationships within datasets
